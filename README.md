# 🎙️ Mini AI Voice Assistant

## Overview
This project is a Python-based Mini AI Voice Assistant that can understand voice commands and perform tasks like opening applications, searching the web, and managing daily activities.

## Features
- Voice command recognition
- Text-to-speech response
- Open applications
- Web search functionality
- To-do list management

## Tech Stack
- Python
- SpeechRecognition
- pyttsx3
- OS module

## How to Run
1. Clone the repository:
   git clone https://github.com/your-username/mini-ai-voice-assistant.git

2. Install dependencies:
   pip install -r requirements.txt

3. Run the project:
   python main.py
